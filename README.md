Entry for the [One Line, No Deadline Met](https://make.fun/c/u-markk-st-one-line-no-deadline-met-6adc00ce) bounty on make.fun: a program that writes one single-line joke giving an excuse for a missed deadline, capped at 200 characters.

## The line

> My deadline filed for an extension without telling me — I'm just here to deliver the paperwork.

## How it works

`main.py` reads the excuse line from `entry.txt`, validates it (a single non-blank line of 1–200 characters), writes it to `/output/entry.txt` for the harness, and prints it to stdout.

```sh
python3 main.py
```

## Files

- `main.py` — entry writer program
- `entry.txt` — the one-line excuse
- `LICENSE` — MIT
